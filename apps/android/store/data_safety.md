# Data Safety Declaration

## Data collected:
- Crash logs (optional, anonymous)
- Performance metrics (optional, anonymous)
- App interactions (optional, anonymous)

## Data NOT collected:
- Personal information
- Conversations
- Files
- Contacts
- Location
- Financial data

## Data sharing:
- No data shared with third parties
- Crash logs shared with Firebase (Google) if opted in

## Security:
- Data encrypted in transit (HTTPS)
- Data encrypted at rest (EncryptedSharedPreferences)
- OAuth tokens secured with Android Keystore
