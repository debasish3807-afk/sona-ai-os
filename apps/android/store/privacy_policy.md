# Privacy Policy — Sona AI OS

Last updated: 2026-08-07

## Data Collection
- We collect minimal anonymous analytics (crash reports, performance metrics)
- All AI processing happens on-device or on your configured server
- No personal data is sent to third parties without explicit consent

## Permissions
- Microphone: Voice assistant features
- Camera: Vision AI and document scanning
- Storage: File access and offline cache
- Internet: AI model communication
- Notifications: Background task alerts

## Data Storage
- Conversations stored locally on device
- Memory and knowledge indexed locally
- OAuth tokens stored in encrypted storage
- No cloud sync without user action

## Your Rights
- Export all your data at any time
- Delete all data from Settings
- Disable analytics in Settings
- Revoke permissions at any time
